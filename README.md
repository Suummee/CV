# Sumeet Telgote — Portfolio

A single-page portfolio site built with plain HTML/CSS/JS and hosted on GitHub Pages.

- **Resumes** — Marketing & Communications and Operations & Events tracks (PDF)
- **Projects** — 19 academic and coursework projects across marketing strategy, digital marketing, communications, and creative/visual design (PDF, filterable by category)
- **Education & Certifications**

## Structure

```
index.html              # single-file site (inline CSS/JS)
assets/resume/           # resume PDFs
assets/projects/         # project PDFs
```

## Updating

Edit `index.html` directly — the project list lives in the `PROJECTS` array near the bottom of the file. Add a PDF to `assets/projects/` and add a matching entry to the array to add a new project.
